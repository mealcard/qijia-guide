# 齐家 App · 使用教程

一个 HTML 文件，25 张幻灯片。
所有图标、二维码、脚本都已嵌入 — **双击文件就能看，不用装任何东西**。

## 怎么打开

直接双击 **`齐家 App 使用教程.html`**：
- macOS · 双击 → 默认浏览器自动打开
- Windows · 双击 → 默认浏览器自动打开
- iPhone / iPad · "文件" App 里点开 → Safari 打开
- 也可以右键 → 用 Chrome / Edge / Safari / Firefox 打开

**不需要 Python，不需要 Node，不需要服务器，不需要联网。**
（联网时字体更漂亮，离线会回退到系统中文字体，内容不受影响。）

## 怎么看

| 操作 | 作用 |
|---|---|
| `→` / `Space` / `PgDn` | 下一页 |
| `←` / `PgUp` | 上一页 |
| `Home` / `End` | 第一页 / 最后一页 |
| `0`–`9` | 跳到对应幻灯片 |
| `R` | 回到第一页 |
| **`V`** | **▶ 播放 / 暂停（自动翻页 · 视频模式）** |
| `+` / `-` | 加速 / 减速（0.5× → 2×） |
| 鼠标点右上角 `PLAY` 胶囊 | 同 V |
| 触屏左 / 右 | 上一页 / 下一页 |

播放时顶部一条金色进度条，最后一页自动停。

## 想存 PDF？

仓库里已附 **`齐家 App 使用教程.pdf`**（25 页，1920×1080）。
也可以任意浏览器打开 HTML → `Cmd/Ctrl + P` → 另存为 PDF，打印对话框里开"背景图形"还原配色。

## 想发给家长

直接微信传这一个 `.html` 文件（约 3.8 MB，远低于 25 MB 限制）→ 对方收到点"在浏览器打开" → 按 V 自动播放。

## 发布到 GitHub Pages

仓库根目录已经有一份 **`index.html`**（与上面的 HTML 同一个单文件），可直接发布：

1. 把这个文件夹推到 GitHub 仓库（任意仓库都行；若仓库名为 `<用户名>.github.io`，则直接是主页）。
2. 仓库 **Settings → Pages → Source** 选 `main` 分支、根目录 `/`，保存。
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/` 即可在线观看，把链接发给谁都能开。

说明：
- 在线版需要浏览器 + 网络；要给"没浏览器 / 离线"的人看，仍用上面的 PDF 或直接发 HTML 文件。
- 页面公开可访问（内含公众号二维码，但不含任何个人数据）。
- 字体走 Google Fonts CDN，在线时更精致，离线自动回退系统字体。
